# StekloProff — исправленная версия для GitHub Pages

Эта версия сделана для репозитория `dzondzon771-rgb/Stekloproff-`, где файлы лежат **в корне**, без папки `assets/`.

## Как загрузить

1. На GitHub откройте https://github.com/dzondzon771-rgb/Stekloproff-
2. В Code нажмите **Add file → Upload files**.
3. Выберите **файлы внутри** этой папки (не саму папку), включая `index.html`, `.css`, `.js`, `.jpg`, `.png` и `.svg`.
4. Подтвердите замену файлов и нажмите **Commit changes**.
5. Подождите завершения GitHub Pages deployment (Actions); затем откройте сайт и перезагрузите **Ctrl+F5** или проверьте в режиме инкогнито.

Не загружайте ZIP как отдельный файл. Распакуйте архив, затем добавьте содержимое папки.

Важно: Если фотографии в репозитории лежат уже в корне, можно заменить только `index.html`. Путь исправлен с `assets/имя.jpg` на `имя.jpg`.

Все фотографии демонстрационные, не являются реальными работами сервиса.
