# StekloProff — версия 3 (обновлённая типографика + подбор моделей)

Откройте `index.html` в браузере или разместите содержимое папки на любом статическом веб-хостинге.

## Что нового
- Новый шрифт **Onest** (загружается с Google Fonts при подключённом интернете; на случай отсутствия сети предусмотрены системные шрифты).
- Отдельный заметный блок «Ваш автомобиль. Точное стекло» с формой быстрого подбора.
- Выпадающий поиск по моделям автомобилей в блоке подбора и в модальном окне.
- Для Toyota присутствуют **Camry 30, 40, 50, 55, 70, 80, Corolla, RAV4, Prado 120/150, Land Cruiser 100/200/300, Highlander, Avensis, Yaris, Hilux**, плюс другие модели.
- Списки для ещё 15 популярных марок. Если модель отсутствует, её можно ввести вручную.
- Поиск по подстроке, навигация стрелками и Enter/Escape, ограниченная высота списка с прокруткой, мобильная адаптация.
- Все основные разделы прошлой версии, логотип, фотографии услуг, переключение RU/KZ/EN и анимации сохранены.

## Как работает заявка
При нажатии кнопки создаётся **черновик сообщения в WhatsApp** с данными авто. На сайте не сохраняются заявки. Для отправки пользователь подтверждает сообщение в WhatsApp. Никакого CRM, складских остатков или серверной обработки нет.

## Перед размещением на stekloproff.kz
Проверить номер телефона, адрес, график, цены, список услуг и список доступных моделей. Модели — подсказки для поиска, не гарантия наличия автостекла. Фотографии — демонстрационные иллюстрации, их рекомендуется заменить реальными снимками сервисных работ. Сделать резервную копию текущего сайта перед заменой.
